## The entry

> The vending machine ate my dollar and gave me nothing, which technically makes it the most honest coworker I have.

The machine steals a dollar and returns nothing — and that, the joke turns, is exactly what makes it the most honest coworker in the building. Everyone who has worked in an office knows the vending machine; nobody expects it to be the moral standard.

## How it works

`main.py` is a deterministic Python 3 program. It writes the line above to `/output/entry.txt` — the same bytes on every run. No network, no randomness, no input.

```sh
python3 main.py
cat /output/entry.txt
```
